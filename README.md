# parallel_request

Выгрузка из ClickHouse **THEATRE_RU** или **THEATRE_ASIA** в `pandas.DataFrame`.
Период делится на чанки, запросы выполняются параллельно, результаты объединяются в памяти.

## Реквизиты

Создайте `.env` в рабочей папке ноутбука и заполните реквизиты нужного региона:

```dotenv
THEATRE_LOGIN_RU=your_ru_login
THEATRE_PASS_RU=your_ru_password

THEATRE_LOGIN_ASIA=your_asia_login
THEATRE_PASS_ASIA=your_asia_password
```

Нужны только логин и пароль выбранного `conn`. Переменные окружения имеют
приоритет над `.env`. Другой путь к файлу можно указать через `env_file`.

## Пример

Замените `your_table` и `created_at` на свою таблицу и столбец с датой.
Шаблоны `{start_date}` и `{end_date}` обязательны и пишутся **без кавычек**.

```python
from parallel_request import extract

query = """
SELECT *
FROM your_table
WHERE created_at >= {start_date}
  AND created_at < {end_date}
"""

df = extract(
    query=query,
    start_date="2026-05-01",
    end_date="2026-05-18",  # 18 мая НЕ входит в выгрузку.
    chunk_type="day",
    workers=6,
    conn="THEATRE_ASIA",  # Или "THEATRE_RU".
)

df.head()
```

**Начальная дата входит в период, конечная — не входит.** В примере выгружаются
данные **с 1 по 17 мая включительно**. Чтобы включить 18 мая целиком, укажите
`end_date="2026-05-19"`.

## Параметры `extract()`

Первые три параметра обязательны; остальные передаются по имени.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `query` | Обязательный | SQL с `{start_date}` и `{end_date}` без кавычек. |
| `start_date` | Обязательный | Включённое начало: строка ISO, `date` или `datetime`. |
| `end_date` | Обязательный | Исключённый конец, позже `start_date`. Те же форматы. |
| `chunk_type` | `"day"` | `hour`, `day`, `week`, `month`, `quarter`, `year` или `TimeChunkType`. Пустая строка недопустима. |
| `workers` | `6` | Целое число > 0: общий максимум одновременных запросов на все серверы. |
| `conn` | `"THEATRE_RU"` | Источник: `THEATRE_RU` или `THEATRE_ASIA`. |
| `env_file` | `".env"` | Путь относительно рабочей папки ноутбука или абсолютный путь. `None` — только переменные окружения. |

Даты могут содержать время, например `"2026-05-01T10:30:00"`.
Обе границы должны быть либо с часовым поясом, либо без него.

## Как работает выгрузка

- `hour`, `day`, `week` делят период на часы, дни и семь дней от начала.
  `month`, `quarter`, `year` — по календарным границам. Последний чанк обрезается по `end_date`.
- Воркеры распределяются по трём серверам выбранного региона. Если чанков меньше,
  число воркеров уменьшается.
- Результат — один DataFrame в памяти.
- Агрегации, `LIMIT` и `ORDER BY` выполняются отдельно для каждого чанка;
  общий итог при объединении не пересчитывается.
- При ошибке подключения, SQL или параметров выбрасывается исключение.
  Частичный результат не возвращается.

Подробная подсказка доступна в IDE, через `help(extract)` или `extract?` в Jupyter.
