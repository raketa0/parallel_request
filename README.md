# parallel_request

Выгрузка данных из ClickHouse THEATRE в `pandas.DataFrame`. Запрос делится на
временные интервалы, выполняется параллельно, а результаты объединяются в одну
таблицу в памяти.

`df = extractor.extract()` возвращает готовый DataFrame. Автоматической записи
в TXT, CSV или другие файлы нет. Серверы THEATRE и база `BookingFormAnalyticsV2`
уже настроены в проекте.

## 1. Установка

Нужен Python 3.10 или новее. Выполните из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 2. Доступ к THEATRE

Если файла `.env` ещё нет, создайте его в корне проекта. Укажите логин и пароль:

```dotenv
THEATRE_LOGIN_RU=your_login
THEATRE_PASS_RU=your_password
```

Если реквизиты уже заполнены, менять файл не нужно. Он загружается автоматически
и исключён из Git. Для подключения нужен сетевой доступ к THEATRE.

## 3. Получение DataFrame

Пример для вашего Python-скрипта в папке `src`. Замените `your_table` и
`created_at` на имя нужной таблицы и её столбца с датой.

```python
from datetime import datetime

import pandas as pd

from DataExtractor import DataExtractor
from time_chunks import TimeChunkType


query = """
SELECT *
FROM your_table
WHERE created_at >= {start_date}
  AND created_at < {end_date}
"""

extractor = DataExtractor(
    query=query,
    start_date=datetime(2026, 5, 1),
    end_date=datetime(2026, 5, 17),
    chunk_type=TimeChunkType.DAY,
)

df: pd.DataFrame = extractor.extract()

# Дальше работайте с df обычными средствами pandas.
print(df.head())
print(f"Получено строк: {len(df)}")
```

Например, если вы поместили код в `src/example.py`, запустите его из корня проекта:

```powershell
python src/example.py
```

Результат находится в переменной `df`. В своём коде можно фильтровать строки,
считать показатели, объединять его с другими DataFrame или возвращать из функции:

```python
def load_data() -> pd.DataFrame:
    return DataExtractor(
        query=query,
        start_date=datetime(2026, 5, 1),
        end_date=datetime(2026, 5, 17),
        chunk_type=TimeChunkType.DAY,
    ).extract()


df = load_data()
```

Второй пример использует импорты и `query` из первого.

## Параметры выгрузки

| Параметр | Что передать |
| --- | --- |
| `query` | SQL-запрос с параметрами `{start_date}` и `{end_date}`. |
| `start_date` | Начало периода: `datetime`, включается в выгрузку. |
| `end_date` | Конец периода: `datetime`, не включается в выгрузку. |
| `chunk_type` | Размер временного интервала, например `TimeChunkType.DAY`. |
| `workers` | Необязательный общий лимит параллельных запросов. По умолчанию — 8. |

В примере выгружается период **с 1 по 16 мая включительно**: для этого
`end_date` задан как 17 мая, 00:00. Начало должно быть раньше конца.

Оба параметра дат в SQL нужно оставлять **без кавычек**. Значения передаются
драйверу отдельно; вручную подставлять даты в строку запроса не нужно.

## Как выбрать размер интервала

| Значение `TimeChunkType` | Разбиение |
| --- | --- |
| `HOUR` | По одному часу от начала периода. |
| `DAY` | По одному дню от начала периода. |
| `WEEK` | По семь дней от начала периода. |
| `MONTH` | По границам календарных месяцев. |
| `QUARTER` | По границам календарных кварталов. |
| `YEAR` | По границам календарных лет. |

Первый и последний интервалы ограничиваются заданным периодом. Для выгрузки
нескольких дней можно начать с `DAY`. Если выбрать `MONTH` для периода внутри
одного месяца, получится один запрос — увеличить параллелизм через `workers`
в этом случае не выйдет.

## Что происходит при вызове extract()

- Вызов ожидает завершения всех запросов и возвращает один `pandas.DataFrame`.
- Каждый интервал обрабатывается один раз. Освободившийся поток берёт следующий.
- Результаты объединяются по строкам в порядке завершения запросов, без общей
  сортировки. При необходимости отсортируйте `df` после получения.
- Если запрос содержит агрегацию, она выполняется отдельно для каждого интервала.
  Общий итог по всему периоду нужно рассчитывать с учётом этого.
- При ошибке подключения или запроса метод выбрасывает исключение; частичный
  DataFrame не возвращается.
- В консоли отображается ход выполнения. Эти сообщения не являются результатом
  выгрузки: результат возвращается через `return`.
